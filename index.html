01

Adaptive Multi-Client RAG Support Agent

An adaptive support agent for small businesses. Each business is a single YAML file. Customers write on Messenger, Instagram, WhatsApp or Telegram and get answers drawn only from that business's own documents. Staff handle several customers at once on a dashboard that writes every case to Excel. WHAT IT DOES: Answers from the client's files only, Replies on the channels customers use, Uses outside apps safely, A desk for staff.

02

RAG-Powered Study Game for Any Book

I built Quiz Showdown to prepare for the Microsoft AI-103 exam. It is a quiz generator that writes questions only from the books and files I choose, and every question cites the page or section it came from. I put my study material in a knowledge folder, pick one or several books, and play the quiz in a “Who Wants to Be a Millionaire”-style game. Because it isn’t hard-coded to one subject, I can drop in notes for any other exam or course and it adapts. Under the hood it uses retrieval-augmented generation (RAG), reranking, adaptive difficulty and strict validation, so the questions stay grounded in my sources and don’t repeat.

03

Signal-only XAUUSD (gold) Analysis Dashboard Agent

I built ApexQuant-XAU, an open-source XAUUSD analysis dashboard that is designed to say "NO TRADE" more than it says "trade". Data quality, macro (FRED), news freeze and spread/liquidity checks run as deterministic gates in code; an LLM (gemini-3-flash by default) only judges chart structure after every gate passes. Signal-only, read-only MT5, DST-aware time zones, MIT licensed. Educational use, not financial advice and not backtested.
