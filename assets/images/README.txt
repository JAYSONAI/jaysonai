IMAGE GUIDE
===========
Drop your images into this folder using EXACTLY these file names.
(Or change the file name in the matching <img src="..."> in index.html.)
Until a file exists, the site shows a labeled placeholder box in its place.

WHO YOU ARE
  profile.jpg                 Portrait photo, 4:5 (e.g. 800 x 1000 px). Friendly, well lit, plain background.
  share.jpg                   Link-preview image, 1200 x 630 px (optional).

PROJECTS
  project-reel.jpg            Thumbnail for the YouTube reel, 16:9 (1280 x 720 px).
  project-motion.jpg          Thumbnail for the Vimeo video, 16:9.
  project-expert-search.jpg   Screenshot of your expert-witness tracking sheet, 16:10.
                              BLUR client and case names first.
  project-data-cleaning.jpg   Screenshot of your Python notebook, 16:10.

CREDENTIALS
  cert-admin-assistance.jpg   Microsoft x LinkedIn certificate, 4:3.
  cert-power-bi.jpg           Pragmatic Works certificate, 4:3.
  cert-tkt.jpg                TKT (Cambridge English) certificate, 4:3.
  diploma-pup.jpg             Diploma or graduation photo, 4:3.
                              Blur ID numbers and other personal details.

TIPS
  * Keep each file under ~300 KB (use squoosh.app or tinypng.com).
  * JPG for photos and screenshots, PNG only if you need transparency.
